# Школа послушания — сайт

Статический сайт проекта (`index.html` + `style.css`). Открывается в браузере прямо из папки, хостинг не обязателен для локального просмотра.

## Структура

- `index.html`, `style.css` — сам сайт.
- `assets/` — логотип и другие изображения сайта.
- `game/` — сюда позже нужно будет положить веб-экспорт игры из Godot (`index.html`, `index.wasm`, `index.pck` и т.д., экспорт из Godot с пресетом Web). Как только файлы появятся в этой папке, верхний блок на главной странице (сейчас заглушка «Скоро») нужно будет заменить на `<iframe src="game/index.html">`.

## Публикация (GitHub Pages)

1. Запушить содержимое этой папки в GitHub-репозиторий.
2. В настройках репозитория: Settings → Pages → Source → ветка `main`, папка `/ (root)`.
3. Сайт появится по адресу вида `https://<юзернейм>.github.io/<репозиторий>/`.
